# Mac UI-прогін — 2026-11-15

Issue #76. Виконав Codex через нативний UI. Це доказ MacCatalyst, не ручного Windows/Android запуску.

## Середовище

macOS 27.3 arm64, Xcode 27.2 (27B52), окремий .NET SDK/workload set 10.0.404, MacCatalyst SDK 27.2.10000, MAUI 10.0.110. Повна нативна Debug-збірка з ad-hoc підписом: **0 warnings, 0 errors**. Глобальний Xcode й попереднє .NET-середовище не змінено.

API: `http://127.0.0.1:5295/`, Development, окрема тимчасова SQLite-база поза репозиторієм. Вхід демо-оператора. Усі показники синтетичні: CO₂ 1900 ppm; температура 21, 22, 22.5, 23.5 і 30 °C. Додано пропущені часові інтервали для перевірки розриву.

## Межі доказів

Роль Viewer, HTTP 403, неправильні пороги, збереження чернетки, повторне підключення, перенаправлення negotiation та завершення каналу при logout перевіряються автоматизованими тестами; таблиця вище не видає їх за ручні дії.

Постійне SecureStorage потребує належного платформного підпису. Ручний Windows/Android UI, iOS runtime і людське рев'ю не підтверджені цим прогоном. CI builds і PostgreSQL smoke мають власні результати у PR. Підготовлений звіт не замінює ці перевірки.
