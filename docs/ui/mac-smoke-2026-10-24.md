# Mac UI-прогін — 2026-10-24

Issue #62. Перевірку виконав Codex через нативний UI; це не перевірка Windows/Android.

## Середовище

macOS 27.0 arm64, Xcode 27.1 (27A9275), .NET SDK 10.0.402, workload set 10.0.402.1, MacCatalyst SDK 27.0.10742, MAUI 10.0.110. Повна Debug-збірка з локальним ad-hoc підписом: 0 errors, 2 відомі CA1711 (AppDelegate/SceneDelegate). MAUIG2045 усунено типізованими прив’язками команд.

API запущено профілем http з development SQLite. Для перевірки додано через endpoint measurements чотири температурні виміри (20, 21, 23, 22.5 °C) за останні чотири години та один CO₂ = 1900 ppm. Дані синтетичні й існують лише в локальній development-БД; у репозиторій не включені.

## Межі перевірки

У цьому ad-hoc запуску системний SecureStorage недоступний; спрацював передбачений memory-only fallback. Постійне сховище з належним підписом, Windows/Android UI, SignalR у клієнті та PostgreSQL потребують окремих перевірок.
