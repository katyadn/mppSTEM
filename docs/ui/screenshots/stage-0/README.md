# Скриншоти Етапу 0

Сюди додайте реальні скриншоти після ручного запуску на Windows: Login, Dashboard, RoomDetails, Alerts та Settings. Укажіть ОС, дату, commit і перевірені переходи. Windows CI перевіряє збірку, але не є доказом ручного запуску; ASCII-макети не замінюють скриншоти.

Локальні скриншоти MacCatalyst, якщо доступні, позначаються окремо й не підтверджують Windows-запуск.
