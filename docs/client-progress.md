# Клієнт Учасника 3 — орієнтир 50%

Оновлено 2026-10-24, issue #46. 50% — орієнтовний обсяг клієнтської частини, а не відсоток усього проєкту або тестового покриття.

## Реалізовані сценарії

| Екран | Реалізація |
|---|---|
| Вхід | Email/пароль, перевірка вводу, POST auth/login → GET auth/me; повідомлення про помилки, відновлення чинної сесії |
| Огляд | GET rooms як PagedResponse<RoomResponse>, картки кімнат, оновлення, пагінація, перехід за RoomId. Чинний endpoint не повертає останніх метрик, тому картки показують «Немає даних» |
| Деталі | GET rooms/{id}, summary/series/comfort; шість метрик, 24 години/7/30 днів, min/avg/max, одиниці, графік із розривами й окремим NoData |
| Сповіщення | GET alerts із фільтрами рівня/стану, пагінація, перехід у кімнату, POST acknowledge лише для Open у Admin/Operator |
| Налаштування | Адреса API у Preferences, профіль, стан збереження сесії, вихід. Зміна сервера очищає сесію |

ViewModels та HTTP-клієнт знаходяться у Client.Core, платформа/сховище/навігація — у Client.Maui. JSON має згенеровані метадані для DTO, зокрема рядкових enum. Клієнт не обчислює доменну аналітику самостійно й не використовує будівлі.

Сесія зберігає access token, час завершення, адресу сервера й профіль. Пароль і refresh token не зберігаються. Відповідно до D-1-001 автоматичного refresh немає: після завершення TTL або 401 потрібен новий вхід. 403 показує відмову в дії без знищення сесії. UI-перевірка ролі не замінює авторизацію сервера.

Платформа використовує [MAUI SecureStorage](https://learn.microsoft.com/en-us/dotnet/maui/platform-integration/storage/secure-storage). Якщо системне сховище недоступне, сесія залишається лише в пам’яті; це видно в налаштуваннях. Plaintext fallback відсутній. Локальний прапорець дозволу відновлення вимикається при виході, навіть якщо видалити keychain-запис не вдалося.

HTTPS використовується для віддаленого API; HTTP дозволений для localhost/127.0.0.1 та Android emulator 10.0.2.2. Перевірка TLS залишається стандартною. Автоматичні HTTP redirect вимкнені, токен прив’язаний до адреси сервера.

## Як перевіряти

```bash
export PATH="$HOME/.dotnet:$PATH"
dotnet build Microclimate.Ci.slnf -c Release
dotnet test Microclimate.Ci.slnf -c Release --no-build
```

У налаштуваннях клієнта вкажіть кореневу адресу сервера, наприклад http://localhost:5195/; клієнт додає api/v1 до маршрутів. На фізичному Android використовуйте доступну HTTPS-адресу сервера, на емуляторі — http://10.0.2.2:5195/.

Актуальний main уже містить auth/rooms/analytics/alerts, прикладну аналітику та EF Core SQLite/PostgreSQL. Серверні реалізації збережено без змін. Клієнт адаптовано до PagedResponse<RoomResponse> та масиву MetricSummaryResponse; вибирається запитана метрика, порожній масив дає NoData.

Після інтеграції локально пройшли всі 137 тестів (44 клієнтські, 43 API, 40 Domain, 6 Application, 4 Infrastructure), Release build має 0 warnings/errors. C#/XAML Compile пройшов; зберігаються два CA1711 warnings платформних AppDelegate/SceneDelegate.

Автоматичні тести охоплюють HTTP через контрольований handler і справжній localhost HttpListener: вхід → кімнати → аналітика → підтвердження сповіщення. Додано BackendWorkflowTests: чинні контролери API + міграції SQLite через ASP.NET Core TestServer, JWT-вхід → кімнати → порожня аналітика → прийом вимірів → погодинна/подобова аналітика → фільтрація/підтвердження сповіщення → logout. Це перевірка реальної серверної реалізації без нативного UI; localhost fixture окремо перевіряє transport. Окремо перевіряються 401/403, завершення сесії, інша адреса сервера, валідація, пагінація, скасування запитів, розриви графіка та відсутність перенаправлення пароля.

2026-10-24 середовище Mac узгоджено: Xcode 27.1 (27A9275), .NET SDK 10.0.402, workload set 10.0.402.1, MacCatalyst SDK 27.0.10742, MAUI 10.0.110. Повна нативна Debug-збірка пройшла з 0 errors і двома відомими CA1711. Перевірено живий клієнт із локальним API/SQLite: login, кімнати, деталі, графік із розривом, 7 днів, перехід зі сповіщення в кімнату, acknowledge та logout. У локальну development-БД додано п’ять тестових вимірів; це не дані фізичного датчика. У поточному ad-hoc запуску SecureStorage недоступний: інтерфейс коректно показує сесію лише до закриття застосунку. Деталі — docs/ui/mac-smoke-2026-10-24.md.
