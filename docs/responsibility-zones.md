# Зони відповідальності

| Учасник | Каталоги | Робота |
|---|---|---|
| 1 | Domain, Application, Infrastructure, SensorSimulator | Предметні моделі, EF Core, прикладні сценарії, аналітика та симуляція |
| 2 | Api, Contracts | HTTP API, DTO, JWT, SignalR, OpenTelemetry |
| 3 | Client.Maui, deploy/, .github/, кореневі файли solution та документація | UI, MVVM, навігація, CI, deployment на наступних етапах та правила репозиторію |

На Етапі 0 Учасник 3 створює лише стандартні порожні проєкти чужих зон. Class1 видалено; WeatherForecast залишається стандартним демонстраційним шаблоном, Worker лише пише час у лог. Єдина зміна Worker — регістр `{Time}`, щоб відповідати аналізатору CA1727.

Клієнт не виконує HTTP-виклики та не визначає DTO до їх погодження з Учасником 2. Межі зон змінює команда через зафіксоване погодження.
